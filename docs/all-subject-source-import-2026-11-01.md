# 승인 Docs 초기 반영 중 확인된 결함

기준일: 2026-11-01. 기존 Preview·독립 테스트 DB 범위. 원본과 기존 학습 기록은 변경하지 않는다.

## 사례 단위 보류

비민법 2차 Docs에는 실제 `0점` 답안 구획과 충돌하는 중복 항목이 있다. 배점을 추정하지 않고 해당 사례 전체를 보류한다. 정상 사례는 기존 등록 경로로 처리한다. 민법 snapshot 동작은 유지한다.

형사소송법 2017년 제23회 문1에서는 같은 공통사실과 `현실답안 1 (5점)` 제목이 두 번 나타나 동일 prompt digest를 만든다. 기존 중복 방어가 이를 거절하면서 뒤의 정상 문항 등록도 중단됐다. 같은 사례 내 동일 대상만 `DUPLICATE_SOURCE_TARGET`으로 보류한다. 다른 사례·연도의 중복 정책은 변경하지 않는다.

- 발생 빈도 F 10/10: 해당 원본 등록 시 재현됨. 사용 빈도 추정.
- 심각도 S 5/10: 해당 문서의 후속 정상 문항 등록 중단. 기존 기록 손상 없음.
- 곱 50: 사례 단위 최소 수정.
- 관련 검사: snapshot·동기화 회귀 19/19 PASS. 실사용 점수 저장 시험을 뜻하지 않는다.

동기화 응답·등록 기록에 보류 사유를 보존하고, 모든 사례가 보류된 문서는 삭제 후보 처리 없이 REVIEW로 남긴다. P1 실제 발행이 있는 경우 `appliedToPublishedBank`가 그 결과를 반영하도록 수정했다.

2차 원본 등록, 암호화 답안키 등록, 승인 고정기준 발행, 실제 사용자 점수 저장은 각각 구분한다. 새 사용자 답안·점수를 만들지 않는다.
