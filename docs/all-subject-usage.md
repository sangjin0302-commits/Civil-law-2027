## 공부하는 순서

해당 클라이언트에서 MCP 연결과 도구 목록이 확인된 뒤 과목·단계·원하는 범위를 말합니다. 예: **“민법 1차 미풀이 10문항 출제해.”** 답안을 O/X 순서대로 제출하면 서버가 저장된 정답키로 채점하고 기록합니다. **“민법 풀이 기록 보여줘.”**라고 요청하면 실제 DB 기록을 조회합니다. 아래 순서는 연결 이후의 사용법이며, 현재 ChatGPT 연결 성공을 뜻하지 않습니다.

2차 예: **“민법 2023년 제2문 전체 소문항을 출제해.”** 공통 사실관계와 소문항·배점을 확인한 뒤, 소문항 번호와 직접 작성한 답안을 제출합니다. 원답을 먼저 변경 없이 저장하고 해당 출제 버전의 고정기준을 조회합니다. 의미요소를 한 번 판정한 결과를 서버가 계산·저장합니다. 답안 작성 중에는 채점을 요청하기 전까지 임의 확정하지 않습니다. 제출하지 않은 소문항은 미제출로 남습니다.

고정 필수 요소마다 완전 충족·의미상 동등은 `1`, 부분 충족은 `0.5`, 오류·누락은 `0`입니다. 소문항 점수는 **인정 요소 합계 ÷ 해당 소문항의 전체 고정 필수 요소 수 × 승인 배점**입니다. 글자 수나 문장 일치율로 계산하지 않습니다. 7개 진단 항목은 참고용이며 점수에 다시 더하지 않습니다. 결과 명칭은 **AI 학습평가 점수**입니다.

기준이 없는 문항은 점수 확정을 차단합니다. 답안마다 기준을 새로 만들거나 없는 배점을 채우지 않습니다. 다른 답안으로 확정 기록을 덮어쓰지 않으며, 재시도에는 같은 요청·세트·제출 내용을 사용합니다.

## Google Docs와 SQL의 역할

[승인 문제은행 폴더](https://drive.google.com/drive/folders/13qonoVJPXFynigPOh5rYy8E-KzF1XMAU)와 하위 폴더의 정상 Docs가 원본입니다. 기존 작성 형식을 유지합니다. AI는 새 시험문항을 생성하지 않습니다. 개발용 `PR5-TEST` Docs 2개는 삭제하지 않고 실제 출제·학습점수 기록에서 제외합니다.

일상 출제·채점·기록은 PostgreSQL 저장본을 사용합니다. 출제할 때마다 Docs 전체를 읽지 않습니다. Docs 동기화는 변경된 원본을 등록·파싱하고 안정키·버전을 보존하는 별도 작업입니다. 출처 재승인을 요구하지 않되 중복·본문 변경·정답키·배점 준비 상태는 확인합니다.

| 구분 | 확인된 상태 |
|---|---|
| 기존 민법 문제 반영 | 기존 SQL 저장본으로 사용. 과거 대조에서 미승인 본문 차이 11건은 보존 |
| 신규 Docs 수동 반영 | 승인 Docs의 명시적 O/X 정답을 암호화키로 저장해 P1 17,645문항 발행. 정답 충돌 1문항은 보류 |
| 동기화 호출 중 P1 자동 발행 | 최신 Preview에 `DOCS_P1_AUTO_PUBLISH_ENABLED=true` 반영·조회 완료. 배포된 유지보수 경로의 실호출 성공은 아직 미확인 |
| 일정에 따른 자동 실행 | 설정하지 않음. Docs 편집만으로 동기화 작업이 예약 실행된다고 안내하지 않음 |
| 비민법 P2 반영 | 원문 미발행 등록 진행 중. 고정기준 등록·문항 발행은 아직 미완료 |

## 시간 측정과 한계

2026-11-01 격리 PostgreSQL 회귀검사에서 P2 점수 저장 p95는 **139.797ms**였습니다. 로컬 테스트 입력의 서버 저장 구간 값이며 AI 의미 판정·ChatGPT·네트워크 시간은 포함하지 않습니다. 실제 배포의 전체 채점 왕복 시간은 아직 측정하지 않았습니다. 이 수치를 사용자 체감 채점 시간으로 안내하지 않습니다.

사용 중 저장 오류가 나면 오류와 세트 ID를 보존하고 같은 요청으로 재시도합니다. 기록 확인 없이 성공이라고 표시하거나 앱 재설치·새 계정 생성을 반복하지 않습니다.
