# 문제 자료 갱신 — 사용자 지정 공식 Google Docs가 정본

> 2026-11-01 최신 결정. 공통 출처 승인 규칙은 저장소 루트 `PROJECT_INSTRUCTIONS.md`의 **사용자 지정 문제은행 폴더 — 출처 승인 규칙**이 우선한다. 사용자 지정 문제은행 루트: https://drive.google.com/drive/folders/13qonoVJPXFynigPOh5rYy8E-KzF1XMAU

- 해당 루트와 하위 과목 폴더의 정상 Google Docs는 소유자가 승인한 문제 원본이다. 기존 공식 Docs를 문서별·문항별로 새로 승인하게 하지 않는다. 공식 Google Sheets는 기존 이력·검산 자료로 보존하고, **일상 공식 문제 출제·채점 기준은 PostgreSQL에 동기화된 Docs 원문과 검증된 비공개 정답키**다.
- 원문 변경을 감지해도 이미 출제한 문항·풀이 기록·원답·과거 버전을 임의 덮어쓰거나 재채점하지 않는다. 변경분은 신규·본문수정·중복후보·삭제후보·정답/해설변경·연결보강으로 구분하고 기존 안정키와 버전 계약을 유지한다.
- 기존 `PR5-TEST` 개발용 합성 Docs 두 개는 폴더에 있지만 실제 시험 기출로 표시하거나 발행·채점하지 않는다(정확한 ID는 공통 지침). 이 두 fixture의 상태를 이유로 정상 공식 Docs 전체에 신규 공식성 증명·승인 절차를 만들지 않는다.
- 신규 정상 Docs는 위치 자체가 승인된 입력원이다. 새 문제를 실제 출제하기 전에 기존 파서·안정키·중복/버전·정답키·배점을 점검하고 발행한다. 미확인 정답을 AI로 생성하지 않는다. 기존 미승인 본문 차이 11건은 무단 반영하지 않는다.
- 운영 Google Docs/Sheets/Apps Script 수정과 운영 DB 전환은 별도 명시적 승인이 필요하다. 수동 유지보수 실행은 권한 있는 경로를 사용하며, 일상 출제에서는 매번 Google API를 읽지 않고 PostgreSQL을 조회한다.
